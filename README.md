# 🚢 Titanic Survival Prediction

A simple Machine Learning web application that predicts whether a Titanic passenger is likely to survive based on passenger and travel information.

## 🔗 Live App

https://titanic-survival-prediction-awqphahbpmrkn5xd2haysv.streamlit.app/

## 📌 Project Features

- Explore the Titanic dataset
- Analyze survival patterns using charts
- Predict passenger survival
- Display survival probability
- Evaluate Machine Learning model performance

## 🤖 Machine Learning Model

**Random Forest Classifier**

### Input Features
- Passenger Class (Pclass)
- Sex
- Age
- Siblings/Spouses (SibSp)
- Parents/Children (Parch)
- Fare
- Embarked

### Target
- `0` – Did Not Survive
- `1` – Survived

## 📊 Data Analysis

The application provides visualizations for:

- Survival Distribution
- Survival by Gender
- Survival by Passenger Class
- Survival by Age Group
- Age vs Fare
- Fare Analysis
